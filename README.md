# RBFA match calendars

Planned matches from rbfa.be, one calendar per team, updated automatically a few times a day.
Each event has the match address; the notes show the pitch, series and age group.

**Subscribe, don't import** (an imported file never updates):

- iPhone: Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar → paste the link.
- Google Calendar (computer): Other calendars → + → From URL → paste the link. Google refreshes subscribed calendars
  on its own schedule, which can take up to a day.

Times are Belgian local time; each match is shown as 1 h 45. Source: rbfa.be. The files in this repo are generated;
don't edit them by hand.
